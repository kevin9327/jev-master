# JevHarness

Agent tool-call gate. Choice allow/ask/deny + irreversibility Score + on-task Noul. Code returns `execute` / `confirm` / `reject`.

Standalone GitHub repo: https://github.com/kevin9327/jev-harness

```bash
python -m jev_master harness --state examples/rm-step.json
python -m jev_master.apps.jev_harness --state examples/read-step.json
```

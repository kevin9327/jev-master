# JevCode

Diff merge gate, not a code generator. Choice review + risk Score + tests_missing Noul. Code returns `merge` / `comment` / `block`.

Standalone GitHub repo: https://github.com/kevin9327/jev-code

```bash
python -m jev_master code --state examples/risky.diff
python -m jev_master.apps.jev_code --state examples/safe.diff
```
